# GitHub Explorer

A simple SwiftUI application built to explore the GitHub users and their repositories. This project was created to practice modern iOS development patterns and Swift's latest features.

## Architecture & Technologies

- **SwiftUI**
- **MVVM**
- **Swift Concurrency**

## Features

- **User Search**: Search GitHub users by username.
- **Profile Details**: Detailed view of user profiles, including bio, follower counts.
- **Repository List**: Browser for user repositories with star counts, descriptions, and language details.
- **Networking Layer**: A generic network service handling API requests, decoding, and custom error states.

## Requirements

- iOS 17.0+
- Xcode 15.0+
